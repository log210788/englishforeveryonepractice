Unit 7 • Lesson: Wishes and desires

Wishes and desires

You can use "I want" and "I would like" to talk about things you want to do. You can also use their negative form to say what you would not like to do.

New language "Would" and "want"
Vocabulary Leisure activities
New skill Talking about ambitions
47.1

FILL IN THE GAPS TO WRITE EACH SENTENCE THREE DIFFERENT WAYS

Click play to listen or use Rec to practice speaking out loud!

They would like to visit Tokyo. / They'd like to visit Tokyo.
I want to eat an orange. / I would like to eat an orange.
You want to learn Spanish. / You'd like to learn Spanish.
We want to go to a café. / We would like to go to a café.
He would like to live in Germany. / He'd like to live in Germany.
We want to swim in a lake. / We'd like to swim in a lake.
